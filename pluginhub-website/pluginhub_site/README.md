# PLUGBASE – kostenlose Plugin-Download-Website

Responsive Plugin-Katalog inklusive Suche, Kategorien, Detailansichten und lokalem Katalog-Editor. Reines HTML/CSS/JavaScript, ohne Build-Schritte oder Backend.

**Starte hier: [ANLEITUNG.md](ANLEITUNG.md)**

Öffne `index.html` für die Website und `admin.html` für den Editor. Die Beispiel-Downloads sind ausdrücklich nur Demo-Dateien. Änderungen aus dem Editor müssen als `plugins.js` exportiert und im Repository veröffentlicht werden.
